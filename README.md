# capyExtended
desafioCapyba with extra features and fixes.

✅ Cadastro de usuário

✅ Autenticação via token

✅ Confirmação de e-mail antes de acessar recursos protegidos

✅ CRUD de itens públicos e privados

✅ Filtros, busca e ordenação na listagem de itens

✅ Apenas usuários autenticados acessam itens privados

✅ Visualização e atualização de perfil do usuário

✅ Alteração de senha com senha atual obrigatória

✅ Logout com revogação de token (endpoint)

✅ Testes automatizados das funcionalidades

✅ Documentação da API com Swagger/Redoc

✅ Projeto pronto para deploy (Render, Heroku, etc.
